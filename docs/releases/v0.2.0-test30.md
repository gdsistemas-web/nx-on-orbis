# NX on Orbis — GD Test 30 (Linux build)

> **Pre-release / hardware validation pending.** This build has compiled, linked and packaged successfully on Linux, but has not yet been validated on a PS4.

## What is new

GD Test 30 continues the `experimental-fastmem` work from tests 25–29 and adds diagnostics for the large Dynarmic slow-path redirect count seen while fastmem is active.

This build adds:

- redirect hotspot tracking at 4 KiB guest-page granularity;
- fixed-size, allocation-free tracking inside the PS4 fault path;
- periodic top-hotspot reports;
- redirect-cause counters;
- `gd-test30` build identification;
- reproducible Linux dependency bootstrap;
- Linux Eden build support;
- Linux PS4 PKG packaging.
